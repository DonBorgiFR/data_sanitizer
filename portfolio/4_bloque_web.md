# Copia para Web Personal (Odoo) — DataSanitizer

Este documento contiene la estructura de texto optimizada para integrar DataSanitizer como un proyecto destacado dentro del sitio web personal (https://borjafelixrojas.odoo.com/), manteniendo el tono de ingeniería de procesos y pragmatismo operativo.

---

## 🖥️ Bloque Destacado de Proyecto (Sección Portafolio / Herramientas)

### 🏷️ Titular
**DataSanitizer: Control y Calidad de Datos en Migraciones ERP**

### 📄 Subtítulo
*Elimina el caos de datos heredados y asegura cargas de staging limpias a la primera.*

### 📝 Descripción Corta
Las migraciones a sistemas ERP como SAP S/4HANA suelen retrasarse debido a la baja calidad y desorden en los datos maestros de origen (materiales, proveedores, clientes). 

**DataSanitizer** es un motor portátil y de ejecución local (*local-first*) que industrializa la depuración de datos. Automatiza el diagnóstico de salud inicial, valida identificadores fiscales y bancarios de forma matemática, autocorrige provincias según códigos postales y audita las consistencias lógicas de controlling antes de exportar plantillas listas para la carga.

---

## 🎯 3 Balas de Valor (Bullets de Impacto)

1.  **Garantía Fiscal y Bancaria Automatizada:**
    Validación matemática estricta de NIF/CIF españoles y códigos IBAN/BIC europeos de forma masiva en milisegundos, erradicando los rechazos bancarios en producción.
2.  **Validación de Consistencia Industrial (MM/PP/CO):**
    Comprobaciones cruzadas de integridad para el Maestro de Materiales, Listas de Materiales (BOMs), Hojas de Ruta y Centros de Coste (Controlling), evitando errores de valoración de stock.
3.  **Privacidad Radical (Local-First):**
    El motor se ejecuta completamente dentro de la máquina local del usuario. La información sensible de clientes, precios o inventarios nunca es enviada a servidores de terceros en la nube.
